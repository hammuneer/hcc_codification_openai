# Clinical Note Codification App

This is a Streamlit app designed to take clinical notes as input and return a table of corresponding HCC (Hierarchical Condition Categories) and ICD-10 codes by utilizing OpenAI's API for medical coding.

## Requirements

- Python 3.7+
- OpenAI Python client library
- Streamlit
- Pandas
